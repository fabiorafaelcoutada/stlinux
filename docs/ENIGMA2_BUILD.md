# Building Enigma2 and other apps for STi7111

This guide explains how to set up the build environment for Enigma2 and other satellite TV applications using the provided STLinux 2.4 toolchain.

## Prerequisites

1.  **Host Environment**: You need a 32-bit Linux environment or a 64-bit Linux with 32-bit compatibility libraries (`libc6:i386`, `libstdc++6:i386`, `zlib1g:i386`, etc.) because the toolchain binaries are 32-bit.
2.  **Dependencies**: Enigma2 requires many libraries. You will need to cross-compile them and install them into the sysroot (`toolchain/opt/STM/STLinux-2.4/devkit/sh4/target`).

Common dependencies include:
- python 2.7 (or 3.x depending on Enigma2 version)
- libfreetype
- libjpeg
- libpng
- libxml2
- libssl
- libcrypto
- libdvbsi++
- libsigc++
- libtuxtxt

## Setting up the Environment

Source the `env.sh` script generated by `setup.sh`:

```bash
source env.sh
```

This sets `CC`, `CXX`, `CFLAGS`, `LDFLAGS` and `PKG_CONFIG_PATH` correctly.

## Building Autotools Projects (e.g., libraries)

Most libraries use `configure`. You can build them like this:

```bash
./configure --host=sh4-linux --prefix=/usr
make
make install DESTDIR=$SYSROOT
```

Note: `make install` will install into `$SYSROOT/usr` because we set `DESTDIR`.

## Building Enigma2

Enigma2 uses `automake`.

1.  Clone Enigma2 source code (e.g., from OpenPLi or OpenATV).
2.  Run `autoreconf -i`.
3.  Configure:

```bash
./configure --host=sh4-linux --prefix=/usr \
    --with-libsdl=no --with-boxtype=sh4
```

(Adjust flags as needed for your specific Enigma2 version).

4.  Build:

```bash
make
```

## Troubleshooting

- **Missing headers**: If the compiler complains about missing headers, ensure you have cross-compiled the dependency and installed it into `$SYSROOT`.
- **Linker errors**: Ensure library paths are correct. The toolchain handles standard paths, but if you install to custom prefixes, add `-L/path/to/lib` to `LDFLAGS`.
